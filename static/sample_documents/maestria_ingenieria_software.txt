MAESTRÍA EN INGENIERÍA DE SOFTWARE
Universidad ICESI - Facultad de Ingeniería

==================================================
INFORMACIÓN GENERAL
==================================================

La Maestría en Ingeniería de Software de la Universidad ICESI forma profesionales especializados en el diseño, desarrollo y gestión de sistemas de software complejos, con énfasis en arquitecturas modernas, DevOps, y metodologías ágiles.

Duración: 4 semestres (2 años)
Modalidad: Presencial con flexibilidad virtual
Horario: Viernes 6:00 PM - 10:00 PM y Sábados 8:00 AM - 5:00 PM
Inicio de clases: Febrero y Agosto de cada año

==================================================
PERFIL DEL CANDIDATO
==================================================

Este programa está dirigido a:
- Ingenieros de Sistemas, Software o Computación
- Desarrolladores de software con experiencia profesional
- Arquitectos de software que buscan actualización
- Líderes técnicos y tech leads
- Profesionales interesados en arquitecturas de software modernas

Experiencia laboral recomendada: Mínimo 2 años en desarrollo de software

==================================================
REQUISITOS DE INGRESO
==================================================

- Título profesional en Ingeniería de Sistemas, Software, Computación o afines
- Experiencia demostrable en desarrollo de software (portafolio de proyectos)
- Conocimientos sólidos de programación orientada a objetos
- Conocimiento de al menos un lenguaje de programación moderno (Java, Python, JavaScript, C#)
- Nivel de inglés B1 o superior
- Examen técnico de programación y diseño de software
- Entrevista con el director del programa

==================================================
PLAN DE ESTUDIOS
==================================================

SEMESTRE 1 - FUNDAMENTOS AVANZADOS:
- Arquitectura de Software
- Patrones de Diseño Avanzados
- Ingeniería de Requisitos
- Metodologías Ágiles y Scrum Avanzado

SEMESTRE 2 - DESARROLLO MODERNO:
- Microservicios y Arquitecturas Distribuidas
- DevOps y CI/CD
- Desarrollo de APIs REST y GraphQL
- Testing Automatizado y Calidad de Software

SEMESTRE 3 - TECNOLOGÍAS EMERGENTES:
- Computación en la Nube (AWS, Azure, GCP)
- Contenedores y Kubernetes
- Arquitecturas Serverless
- Seguridad en Aplicaciones Web

SEMESTRE 4 - ESPECIALIZACIÓN:
- Proyecto de Grado (desarrollo de software real)
- Electiva de Profundización:
  * Frontend Avanzado (React, Angular, Vue)
  * Backend y APIs de Alto Rendimiento
  * Arquitectura de Datos y Big Data
  * IoT y Edge Computing
  * Blockchain y Web3

==================================================
COMPETENCIAS QUE DESARROLLARÁS
==================================================

- Diseño de arquitecturas de software escalables
- Implementación de microservicios y sistemas distribuidos
- Automatización con DevOps y CI/CD
- Gestión de proyectos de software con metodologías ágiles
- Desarrollo de APIs robustas y seguras
- Optimización del rendimiento de aplicaciones
- Implementación en cloud (AWS, Azure, Google Cloud)
- Testing automatizado y aseguramiento de calidad
- Liderazgo técnico de equipos de desarrollo
- Gestión de deuda técnica y refactoring
